# 听屿音乐

听屿音乐 Windows / Android 官方下载仓库。本仓库仅发布安装包、版本说明和更新信息，**不提供应用源码**。

- [官网下载](https://tingyu-music.mintysole4.chatgpt.site)
- [发行版本与安装包](https://github.com/DHGMM/TingyuMusic/releases)

## 安装

- Windows：下载文件名以 `Windows-x64-Setup.exe` 结尾的安装程序。
- Android：下载文件名以 `Android.apk` 结尾的安装包，最低 Android 8.0。
- 应用内更新：设置 → 系统与更新 → 更新说明 JSON 地址，填写 `https://tingyu-music.mintysole4.chatgpt.site/latest.json`，然后检查更新、下载并安装。

安装包保留开发者提供的内置音源授权；首次使用需联网核验，实际资源及服务可用性以来源返回为准。下载更新后由应用核验 SHA-256。
