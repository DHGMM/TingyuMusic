# 听屿音乐

听屿音乐 Windows / Android 官方下载仓库。本仓库仅发布安装包、版本说明和更新信息，**不提供应用源码**。

- [官网下载](https://tingyu-music.mintysole4.chatgpt.site)
- [发行版本与安装包](https://github.com/DHGMM/TingyuMusic/releases/latest)

## 安装与更新

- Windows：下载文件名以 `Windows-x64-Setup.exe` 结尾的 64 位安装程序。
- Android：下载文件名以 `Android.apk` 结尾的安装包，支持 Android 8.0 及以上的 ARM64 / x86_64 设备。
- **Windows 0.21.1 / Android 1.4.1 起：进入 设置 → 系统与更新 → 检查更新，直接使用官网，无需填写地址。升级会清除旧自定义更新地址。**
- 旧版 0.21.0 / 1.4.0 可先从官网下载新版覆盖安装，后续直接在软件内检查更新。
- 也可从已配对电脑检查局域网更新。安装包完整下载并核验 SHA-256 后，再由你确认安装。

安装包保留开发者提供的内置音源授权；首次使用需联网核验，实际资源及服务可用性以来源返回为准。
